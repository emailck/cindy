## CLI 实际修复

- START-5：CLI 显式开启增量批量查询。第一个 Skill 之外的新分支追加预取，公共祖先按精确 URI 去重。每连接沿用 64×3 条合成请求预算，耗尽仅停止优化，真实查询与 Skill 数量不受限。内部 ID 跨批次唯一；已有文件、权限错误不缓存作不存在；写操作/进程启动/启动结束仍失效。未知编码直接转发，不再消耗首次规范 URI 的预取机会。
- START-6：CLI 显式开启普通本机分配兼容。已授权 guest 且无 direct executor 时，allocate 返回既有 null，旧 Desktop 继续原目标普通启动，不再进入 INVALID 异常路径。仍有一次请求，不能声称节省两秒。无租约或授权扩大。
- 已逐段静态核对分支、权限顺序、参数匹配与请求预算；Desktop 目录无 diff，diff 空白检查通过。本轮未运行测试、类型检查或构建。
- 未缓存跨任务配置或合并不同 cwd 的 config/read，未共享受邀者引擎。81 秒现场改善幅度仍未验证。
- 管理台启动按用户单独授权操作，使用已有管理台产物；不等于 CLI 新代码已打包进容器。
